Local Model Access demo

Get the model file

Put one copy of the model in the Files app. Every site that approves it can then use that same copy.

Two ways to save it

B. Download with the browser (recommended). A normal download: on iPhone, Safari's own downloader saves it to Files › Downloads and keeps going in the background. It works in a Safari tab, not in a Home Screen app. You can move it to On My iPhone › Models afterwards.

A. Download into this page, then Save to Files (small files only). A progress bar, and it resumes if it stops; then Save to Files. On iOS, very large files fail through the share sheet, so use B for real models.
