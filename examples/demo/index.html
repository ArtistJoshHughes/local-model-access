Local Model Access demo

One model file kept in the Files app, used by two different sites for two different jobs. Neither site downloads its own copy or keeps one.

Steps

  1. Get the model file: save the test model into Files (two ways to try).
  2. Site A: model checker: pick the file, check it, measure read speed. Then pick it again.
  3. Site B: GPU job: pick the same file, stream it into the GPU, run the job.
  4. Come back here and copy the report.
